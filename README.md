## 🎮 游戏简介

《AFO：结束？开始？》是一款基于浏览器的高中文化课学习模拟游戏。玩家将扮演一位从信息学竞赛（OI）退役的选手，在52周的时间内，通过策略性的选择平衡学习、休息、社交、经济等多维度状态，最终在高考中取得理想成绩。

为照顾不同地区、选科组合和背景的玩家，本作对“四选二”科目组合做了简化：统一经营语文、数学、英语、物理、化学、生物六科，以六科能力等权平均取整计算游戏成绩指数。这里不模拟真实选科、赋分或招生资格；学校与项目均为虚构。

蓝色活页本贯穿这一年，保存学习、生活与竞赛旧稿。

## ✨ 核心特色

### 🎯 策略性游戏机制
- **每周3次操作限制**：必须在有限资源下做出最优决策
- **多维度属性系统**：精力、压力、健康、心理、经济、人际关系相互影响
- **真实的高中生活模拟**：课程表、作业、模考、假期等完整系统

### 📚 丰富的游戏内容
- **52周完整学年**：从AFO第一天到高考结束
- **随机事件**：学习、关系、健康、回忆、经济、校园特殊事件六大类别，共360条内容；缺少所需真实记录的条目暂不进入抽取池
- **故事剧情**：36段主线、6条可选支线、4段主动回忆；主线与支线不消耗常规行动
- **成就系统**：基础、状态、学科、关系、活动、特殊、结局七大类成就
- **不同结局**：9个主结局；考后主动选择去向，并组合家庭、友情、旧队友、感情、身心与OI六组独立后记

### 🎨 精美的界面设计
- **现代化玻璃拟态UI**：美观的渐变背景和毛玻璃效果
- **响应式布局**：适配桌面和移动设备
- **实时状态监控**：直观的进度条和统计面板
- **事件日志系统**：记录所有重要事件和选择

## 🕹️ 游戏玩法

### 核心状态管理
- **精力值**：学习、活动消耗，休息恢复
- **压力值**：考试、作业增加，休息、活动减少
- **健康值**：熬夜、压力降低，锻炼、休息提高
- **心理值**：心理咨询、积极事件提高
- **经济值**：兼职、父母支持获得，购买资料消耗

### 学科能力提升
- **六大学科**：语文、数学、英语、物理、化学、生物
- **竞赛背景加成**：数学和物理有额外学习效率
- **心理状态影响**：心理状态直接影响学习效率
- **模考复盘**：依据实际模考的两门最低分科目复做基础材料，配合后续主动学习巩固
- **共同学习**：关系达到60可与同学核对教材，或请任课老师辅导对应学科；每周最多一次

### 人际关系系统
- **8个关系对象**：班主任兼物理老师、数学老师、语文老师、英语老师、同桌、旧队友、父母、校园记录同学；原教练参与叙事，不占关系槽
- **关系影响**：关系好坏影响学习支持和心理状态
- **可选支线**：满足剧情与周数条件后主动查看；关系数值不替角色作出感情决定

4. **👥 社交** - 选择已有关系对象交流，改善对应关系
5. **💭 回忆** - 回忆竞赛往事，影响心理状态
6. **📝 模考** - 参加模拟考试检验学习成果
7. **✏️ 作业** - 完成作业巩固知识
8. **🎉 活动** - 参加课外活动丰富经历
9. **💰 经济** - 管理零花钱和支出
10. **本周剧情与支线** - 查看主线、主动进入支线或继续关闭的窗口

## 📊 游戏系统详解

### 阶段目标系统

目标按明确的截止周结算，作业条件在新一周重置前检查；未达成仍可继续游戏。

### 学习与状态安排

心理值达到85后，继续提高不会再增加学习倍率；心理值仍可提高到100，并参与剧情与身心后记。压力的效率惩罚连续变化，焦虑与低精力的惩罚有所减轻。午睡偏重补精力，听音乐可缓解轻度焦虑，睡眠、放松和咨询各有用途。

复盘给当场两门最低分科目各加3能力，压力减5、焦虑减6；此后的三周内，两次相关科目的主动学习增益额外增加20%。新提示覆盖旧提示，不能叠加或重复领取。低分不代表已经记录了逐题错题。共同学习降低压力和焦虑、略微改善对应关系，增长按当前状态与学科能力计算；同学可一起核对六科，老师只辅导对应科目。

### 天气与季节系统

天气影响学习效率，随机事件使用明确的天气条件。52周为抽象学年，不对应真实日期、节日或招生政策。

### 假期系统

假期提供状态支持，仍使用每周三次常规行动；单次行动和剧情不会额外缩短全年。

## 🏆 成就系统

### 成就类别
1. **基础成就**：完成周数、累计时长
2. **状态成就**：达到特定状态值
3. **学科成就**：单科或全科达到高分
4. **关系成就**：与特定角色关系良好
5. **活动成就**：参加特定活动次数
6. **特殊成就**：完美一周、压力管理等
7. **结局成就**：按主动确认的去向与成绩档解锁主结局

### 隐藏成就

支线成就按实际完成次数计数，主动回忆与OI聚会分别记录。

### 🎭 故事系统

选择前显示效果与费用；模考相关正文只读取真实记录。剧情依次显示，不互相覆盖，每段只结算一次。

第52周先完成考前剧情、冻结成绩，再进入考后剧情与去向选择。升学按95、90、80、70、60分档显示六种主结局；复读、休整、工作与继续学习对所有成绩开放，须主动确认。身心状态只决定后记，考后不再扣分。

### 随机事件

每周最多一条，每条每局一次；同类负面事件至少冷却三个完整周。状态处于高压力、高焦虑或低健康、低心理时，不抽取继续恶化对应状态的事件。付费项余额不足时禁用并保留免费退路。

退款、押金、补偿等事件必须有对应交易记录；目前无法验证的条件会排除该事件，不凭文案创造历史交易。

```
AFO-Simulator/
```

### 技术栈
- **HTML5**：游戏结构
- **CSS3**：现代化UI设计，玻璃拟态效果
- **JavaScript**：游戏逻辑和交互
- **响应式设计**：适配不同设备

### 游戏状态管理
游戏使用单一`gameState`对象管理所有状态，包括：
- 时间系统（周、日、季节）
- 核心状态（精力、压力、健康等）
- 学科能力（六科分数）
- 人际关系（8个关系对象）
- 游戏进度（成就、事件、统计）

## 🚀 快速开始

1. 克隆或下载本项目
2. 直接打开 `index.html` 文件即可开始游戏
3. 无需安装任何运行依赖；保持两个 `narrative*.js` 文件与 `index.html` 在同一目录

内容稿更新后可运行 `python scripts/build-narrative.py` 重新编译离线数据。运行 `node scripts/simulate.js --check` 和 `node scripts/check-balance.js` 检查关键逻辑；`node scripts/balance-simulate.js --seeds=200` 可复现21种策略的模拟，输出默认保存在本地 `analysis/3.0.1/`。试玩运行实际游戏函数，每局包含52周、156次行动；浏览器用于最后检查界面。
