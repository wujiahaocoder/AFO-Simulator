# AFO：结束？开始？

![Version](https://img.shields.io/badge/Version-3.3.2-blue)
![License](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey)

一款可以离线游玩的学习模拟游戏。退役 OI 选手重新回到文化课课堂，用 52 周安排学习、休息、关系与生活。

## 开始

下载仓库，将 `index.html`、`dashboard.css`、`narrative.js`、`narrative-data.js` 放在同一目录，用现代浏览器打开 `index.html`。无需安装依赖。

语文、数学、英语、物理、化学、生物统一按六科经营，能力范围 0—100。最终成绩指数为六科等权平均取整，不模拟真实高考赋分、分数线或招生资格。学校与项目均为虚构。

## 每周安排

每周三次常规行动，周末统一处理作业和故事。

| 按键 | 操作 | 用途 |
|---|---|---|
| 1 | 学习 | 独立练习，或选择伙伴共学 |
| 2 | 休息 | 睡眠、午睡、放松、音乐或咨询 |
| 3 | 锻炼 | 改善健康、缓解压力 |
| 4 | 社交 | 指定对象交流 |
| 5 | 回忆 | 阅读旧竞赛片段；每个片段每局一次，确认后消耗10精力 |
| 6 | 模考 | 考试与复盘一起完成，每局最多五次 |
| 7 | 活动 | 社团、志愿活动、讲座、知识竞赛或 OI 聚会 |
| 8 | 经济 | 家教、资料、网课与家庭支持 |
| 9 | 蓝本 | 回看已有牵挂，或继续尚未读完的故事 |
| 0 | 结束本周 | 安排作业，阅读故事，进入下一周 |

Esc 收起窗口；有窗口打开或在输入框内时，数字键不会触发主面板操作。按住 Shift 可查看快捷键。重新开始位于页首角落，并会先确认。

### 学习与共学

独立练习按科目消耗20—35精力。数学、物理保留竞赛背景加成。心理、压力、焦虑、精力和健康共同影响学习收益；心理超过85不再增加学习倍率。

共学在“学习”菜单中选择伙伴，需一次行动、20精力、健康至少50，对应熟悉程度至少60，每周最多一次。菜单同时显示未解锁对象和条件。

同桌、旧队友、林知夏可讨论六科；班主任兼教物理，数学、语文、英语老师各辅导对应科目。共学按当前状态增长能力，压力与焦虑各减4，对应熟悉程度加2，不消耗独立练习的复盘提示。

### 模考与复盘

一次模考含一次复盘，共消耗一次行动、40精力，健康至少60。复盘按当场真实表现选出最低两科，各增加3点能力，压力减5、焦虑减6。接下来三周内，两次相关科目的独立练习增长额外增加20%；新提示覆盖旧提示，不叠加。低分记录不等于逐题错题记录。

### 周末作业

作业不占三次行动。结束本周时统一选择：

- 完成本周剩余作业：每科5精力、能力加0.5。六科全做需30精力，班主任熟悉程度加3，对应数学、语文、英语老师各加2，焦虑减2。
- 先做最弱两科：每科5精力，完成部分按比例结算，其余自动欠交。
- 有旧欠交时，可完成本周并补交最多两科次旧作业；每科次另需5精力，能力加0.3、班主任熟悉程度加1。
- 先留出休息时间；关闭窗口或按 Esc 也采用此安排，未完成部分自动登记。

六科全未完成时：精力加8、压力减3，班主任熟悉程度减5，数学、语文、英语老师各减3，焦虑加2。部分未完成时，通用效果按未完成科数占六科的比例结算；任课老师只在对应科目未完成时降低熟悉程度。欠交会跨周保留，面板显示科次，可在后续周末补交。每周只结算一次，刷新不重复登记。

### 阶段目标

当前阶段在截止前首次达标，立即领取奖励并保留达成结果；截止周不会重复发奖。面板显示可得奖励和实际领取数值，所有属性遵守0—100上限。原奖励全部因满值无法生效时，转为20元资料补贴。选做挑战在截止周记录，不影响主要奖励。

| 截止周 | 主要条件 | 奖励 |
|---|---|---|
| 5 | 全科平均≥20、压力<40、健康≥80 | 精力+10、压力-5 |
| 10 | 至少两科≥30 | 心理+5、金钱+100 |
| 15 | 全科平均≥35、压力<30 | 健康+5、压力-10 |
| 25 | 全科平均≥50 | 精力+15、心理+10 |
| 35 | 全科平均≥60、心理>70 | 压力-15、健康+10 |
| 45 | 全科平均≥75、压力<20 | 精力+20、心理+15 |

## 故事与结局

36段主线、46段支线、4段主动回忆，以及多类随机事件。结束本周后主线自动延续，根据学科能力、状态、熟悉程度和实际行动进入已有分支，只需阅读后继续。主线不再要求挑选路线，也不用另选学习科目。支线符合面板条件和既有经历时自动弹出，仍可选择如何回应；不展示作者排期标签，正文中的真实约定日期和模考周次会保留。随机事件也在周末处理，每周最多一条、每条每局一次。

关系对象为班主任、数学老师、语文老师、英语老师、同桌、旧队友、父母和林知夏。熟悉程度不代表对方同意恋爱、原谅或提供支持。感情线保留朋友、慢慢了解、拒绝、明确互相喜欢与结束等真实记录；仅提高熟悉程度不会自动确认恋爱。原教练参与故事，不占数值槽。

蓝本仅回看实际发生的牵挂与答复，不扣行动，也不提前泄露结果。错过约定会保留相应记录，不会在结局自动和好或补偿。

完成第52周后冻结成绩，再阅读考后故事，比较升学、复读、休整、工作与学习四种去向。四种方向都可查看并返回，实际申请、材料和筹备事项仍由玩家确认，最终确认后不可改变。保留九个主结局档位，以及按实际经历结算的人物和生活后记。

## 进度保存

行动、周末作业、故事和奖励结算后自动保存，不再设置手动保存按钮。进度属于当前浏览器和访问地址，更换浏览器或地址不会自动同步。本地存储不可用时界面会提示。关闭故事后可点“继续阅读”恢复；周末中刷新也会接续当前步骤。

沿用既有存档格式，兼容已有3.x存档；已结算的阶段不补发奖励，缺少的新记录不会补造。旧存档中尚未结束的主线将进入当前状态对应的分支。
