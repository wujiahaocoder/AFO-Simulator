# AFO：结束？开始？

![Version](https://img.shields.io/badge/Version-3.1.11-blue)
![License](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey)

一款可离线游玩的浏览器学习模拟游戏。你是一位结束信息学竞赛（OI）生涯、重新回到文化课课堂的学生，需要在52周里安排学习、休息、关系与开支。蓝色活页本记录这一年的练习、旧稿、误会和选择；考试结束后，你也可以决定下一步如何生活。

## 开始游戏

1. 下载本仓库，或将仓库克隆到电脑。
2. 保持 `index.html`、`narrative.js`、`narrative-data.js` 在同一个文件夹。
3. 用浏览器打开 `index.html`，点击“开始游戏”。

无需安装运行依赖。建议使用支持本地存储的现代浏览器。

## 科目与成绩

**为照顾不同地区、选科组合和背景的玩家，游戏对“四选二”科目做了简化。** 所有玩家统一经营语文、数学、英语、物理、化学、生物六科，不再单独选择组合。

各科能力范围为0—100，最终成绩指数按六科能力等权平均取整。数学和物理的主动学习保留竞赛背景加成。该指数不模拟真实高考总分、赋分、分数线或招生资格；学校与项目均为虚构。

## 安排这一年

每周最多三次常规行动。精力、压力、焦虑、健康、心理和金钱会影响可用行动与学习收益；只追求高状态会占用学习时间，只顾学习也会积累负担。

| 操作 | 用途 |
|---|---|
| 学习 | 选择一科进行独立练习；不同科目消耗的精力与成长幅度不同 |
| 休息 | 选择睡眠、午睡、放松、音乐或咨询，处理不同状态需求 |
| 锻炼 | 改善健康、缓解压力 |
| 社交 | 指定已有关系对象，改善本次交流的对应关系 |
| 回忆 | 主动阅读竞赛片段；确认选择后消耗一次行动与10精力，每个片段每局一次 |
| 模考 | 查看六科实际表现；每局最多五次，需要40精力、健康至少60 |
| 模考复盘 | 根据已发生的考试记录巩固两门薄弱科目 |
| 共同学习 | 与关系达标的同学或任课老师一起核对课内问题，每周最多一次 |
| 作业、活动、经济 | 完成课内任务、参加课外活动、管理收入与支出 |
| 本周剧情与支线 | 查看可进入的故事，或继续尚未完成的剧情 |
| 结束本周 | 结算本周剧情与事件，推进到下一周 |

主线与可选支线不占常规行动；主动回忆按菜单所示费用结算。打开菜单或取消尚未确认的选择不会扣除该项费用。阶段目标按截止周检查，未达成仍可继续这一年。

### 阶段目标

目标卡片展示每项主要条件的当前值、要求与完成状态。综合进度是各项条件进度的等权平均；全部主要条件满足才算达成，截止周结束时按届时状态结算并发放原有阶段奖励。

| 截止周 | 主要目标 | 选做挑战 |
|---|---|---|
| 第5周 | 全科平均≥20、压力<40、健康≥80 | 无 |
| 第10周 | 至少两科能力≥30 | 班主任关系≥60；余额≥300元 |
| 第15周 | 全科平均≥35、压力<30 | 当周完成至少5科作业 |
| 第25周 | 全科平均≥50 | 至少一科能力≥70；与校园记录同学有内容的交流至少2次 |
| 第35周 | 全科平均≥60、心理>70 | 累计完成至少3次模考 |
| 第45周 | 全科平均≥75、压力<20 | 至少两位对象的熟悉程度≥60 |

选做挑战各自记录截止周的完成情况，不影响主要目标或阶段奖励，也不额外增加数值奖励。第25、45周的关系挑战完成后会留下蓝本便签。有内容的交流包括实际参与的改稿、采访、小群问题及指定对象的社交或共学，不要求恋爱。目标卡片可展开上次结算，查看当时各项条件与未达成原因；新记录随存档保存。

### 复盘与共同学习

每场模考在当周及后三周内可复盘一次，消耗一次行动、20精力。按当场实际分数选出最低两科，各增加3点能力，压力减5、焦虑减6。复盘当周及后三周内，两次相关科目的主动学习增益额外增加20%；新提示覆盖旧提示，不叠加。低分记录不等于逐题错题记录。

共同学习需要一次行动、20精力、健康至少50，以及对应关系至少60。每周最多一次：同学可一起查六科教材，班主任兼物理老师、数学老师、语文老师和英语老师只辅导自己的学科。增长取决于当前状态与能力，压力和焦虑各减4，对应关系加2；共同学习不消耗独立学习的复盘提示。

### 状态管理

心理达到85后，继续提高不再增加学习倍率；心理仍可到100，并参与剧情和身心后记。压力的效率惩罚连续变化，焦虑与低精力会降低收益。

午睡补充20精力并缓解少量焦虑；音乐补充少量精力、缓解焦虑并提高心理。睡眠更适合补精力与健康，放松偏重减压，咨询需要100元并提供较强的焦虑与心理支持。根据当前短缺选择休息方式，仍要留出练习时间。

## 故事与结局

游戏包含36段主线、34段可选支线、4段主动回忆，以及学习、关系、健康、回忆、经济和校园特殊事件六类随机内容。可选支线注明截止周；作出约定后若错过最后的机会，记录会保留期限已过的结果。随机事件每周最多一条、每条每局一次；需要交易、物品或具体行动记录才能成立的事件，只在游戏有对应证据时进入抽取池。

八个数值对象为班主任、数学老师、语文老师、英语老师、同桌、旧队友、父母和校园记录同学。数值表示熟悉程度，人物起点不同；高熟悉程度不能保证喜欢、信任或某项支持。原教练参与故事，不占数值槽。朋友的后记也会区分偶尔联系与有许多实际共同经历的交流。

这一年的基调偏向遗憾。认真准备、沟通和赴约，也可能遇到没有同样的喜欢、仍未弥合的分歧、取消的指导、未写完的稿与已经关闭的机会。失去的事会明确留下，不会在后记里自动和好、复合或得到补偿。少数约定仍有能够完成的具体路径；没有参与的支线也不会被补造为一场决裂。

感情记录区分主动朋友、被拒后朋友、告白被拒绝、慢慢了解、明确互相喜欢、喜欢后结束与暂不命名。两次选择走近不会自动确认恋爱；她已经说出的拒绝不能靠提高熟悉程度改写。

完成第52周考前剧情后，游戏冻结成绩，再进入考后剧情与去向确认。保留九个主结局档位，并根据实际申请、筹备和经历呈现相应变体。升学页可以明确偏好岚川或北辰，并记录递交的材料；岚川参考指数90，北辰参考指数95且须完整研修说明，结果使用本次冻结成绩。四种去向都可查看、返回和保存，确认后不能改动这一局的去向。

家庭、同桌、旧队友、感情、身心、OI、四位老师及本次去向分别结算后记。每条线都有实际可达的遗憾：复读可能错过第一期住宿，休整后仍可能无法执行有期限的活动，工作落实也可能失去当期课程。主动选择朋友、退役、复读、休整或工作本身不算坏结局；落空的是这条路上明确期待过的具体事情。

## 保存与快捷键

行动和剧情结算后会自动保存，也可点击“保存进度”。进度保存在当前浏览器、当前访问地址下的本地存储中；更换浏览器或访问地址不会自动同步。若本地存储不可用，界面会提示。关闭剧情窗口后可从“继续未完成的剧情”恢复，考后也可先保存再决定去向。

“重新开始”会先询问是否清除当前进度。3.1.0兼容3.0.0、3.0.1和3.0.2存档：已结算的阶段保留原结果，不补算奖励；尚未结算的阶段采用新条件。旧存档没有分项结算记录时会明确说明；缺少新增经历时不会补造拒绝、分手、失约或申请失败。

| 按键 | 操作 |
|---|---|
| 1—5 | 学习、休息、锻炼、社交、回忆 |
| 6—9 | 模考、作业、活动、经济 |
| 0 | 结束本周 |
| Shift | 显示快捷键提示 |
| Esc | 关闭弹窗 |

- 新增“四个人再也坐不齐”遗憾支线：一起度过的晚上真实发生，毕业后的固定四人安排仍会结束，单独的友情或喜欢无法替它补席。

- 新增“没有备份的声音”遗憾支线：明确想保存、实际查找与原声损坏分别留档；再认真尝试或后来重聚，都不能补回那一晚的录音。

- 响椅子和旧合照的回忆对应实际联系范围：疏远后保留旧群问候，偶尔联系时可聊一件小事；既有遗憾不会因此自动消失。
